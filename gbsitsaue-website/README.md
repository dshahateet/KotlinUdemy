# gbsitsaue.com — PHP + MySQL website (Arabic / English)

موقع شركة خدمات تقنية معلومات مبني بـ PHP و MySQL بدون أي إطار عمل (بدون Laravel)، باللغتين العربية (RTL) والإنجليزية، مع لوحة تحكم لتعديل كل المحتوى.

## المتطلبات
- PHP 8.0 أو أحدث (مع إضافات `pdo_mysql` و `mbstring` و `fileinfo`)
- MySQL 5.7+ أو MariaDB 10.3+
- استضافة Apache (cPanel أو ما يشبهها). ملف `.htaccess` جاهز.

## خطوات الرفع على الاستضافة
1. ارفع محتويات مجلد `gbsitsaue-website` إلى `public_html` الخاص بالدومين `gbsitsaue.com`.
2. أنشئ قاعدة بيانات ومستخدماً من cPanel ← MySQL Databases.
3. افتح phpMyAdmin واستورد الملف `database.sql`.
4. عدّل `config.php`: بيانات الاتصال `DB_NAME` و `DB_USER` و `DB_PASS`. الإيميل `info@gbsitsaue.com` والدومين مضبوطان مسبقاً.
5. أعطِ مجلد `uploads/` صلاحية الكتابة (755 أو 775).
6. أنشئ صندوق البريد `info@gbsitsaue.com`، وأيضاً `no-reply@gbsitsaue.com` المستخدم كمرسل لرسائل النموذج.
7. فعّل شهادة SSL. ملف `.htaccess` يحوّل الزوار تلقائياً إلى `https://gbsitsaue.com`.
8. احذف `database.sql` من السيرفر بعد الاستيراد.

## لوحة التحكم
- الرابط: `https://gbsitsaue.com/admin/`
- المستخدم: `admin`، كلمة المرور: `ChangeMe@2026`. **غيّرها فوراً** من صفحة Change Password.
- من اللوحة تقدر:
  - تعدّل الخدمات وتفاصيلها والأسئلة الشائعة.
  - تعدّل "لماذا تختارنا" وشهادات العملاء وفريق القيادة والشركاء والمكاتب.
  - تدير المدونة ودراسات الحالة.
  - تقرأ رسائل نموذج التواصل.
  - تعدّل إعدادات الموقع، مثل الهاتف والواتساب والعنوان والروابط الاجتماعية والأرقام والنصوص.
- كل حقل نصي له نسخة إنجليزية ونسخة عربية.

## يجب تعديله قبل الإطلاق
- **رقم الهاتف والواتساب والعنوان**، من Site Settings. القيم الحالية `+971 4 000 0000` مؤقتة.
- **الأرقام** (سنوات الخبرة، المشاريع، الشركاء)، من Site Settings.
- **شهادات العملاء، فريق القيادة، الشركاء**: أضفت سجلات فارغة **مخفية**. أدخل البيانات الحقيقية مع الصور والشعارات، ثم فعّل "Visible on website".
- المقالة ودراسة الحالة الموجودتان مجرد أمثلة، استبدلهما بمحتواك.

## هيكل الملفات
```
config.php              إعدادات قاعدة البيانات والدومين والإيميل
index.php               الصفحة الرئيسية
services.php            قائمة الخدمات
service.php?slug=...    صفحة الخدمة (Cloud, Cyber Security, ...)
about.php               من نحن
blog.php / case-studies.php / post.php?slug=...
contact.php             اتصل بنا  (contact-submit.php يحفظ الرسالة ويرسلها إلى info@)
lang/en.php, lang/ar.php نصوص الواجهة الثابتة
partials/               الهيدر والفوتر والنماذج
admin/                  لوحة التحكم
assets/                 CSS / JS / الشعار
uploads/                الصور المرفوعة من اللوحة
database.sql            الجداول + المحتوى الأولي
```

## اللغة
- التبديل يتم بالزر أعلى الصفحة، أو بإضافة `?lang=ar` أو `?lang=en` للرابط، ويُحفظ الاختيار في cookie.
- اللغة الافتراضية تُضبط من `DEFAULT_LANG` في `config.php`.

## الأمان
- كل الاستعلامات تستخدم PDO prepared statements.
- حماية CSRF على كل النماذج، وحقل honeypot ومهلة زمنية ضد السبام في نموذج التواصل.
- كلمات المرور مشفرة بـ `password_hash`، وتسجيل الدخول يُقفل مؤقتاً بعد 5 محاولات فاشلة.
- مجلد `uploads/` يمنع تشغيل ملفات PHP، ولا تُقبل فيه إلا الصور.
